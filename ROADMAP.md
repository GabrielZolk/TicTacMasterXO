# TicTacMasterXO — Roadmap de Features Futuras

## Implementado (v2.1.0)
- 8 modos de jogo (Classic, Infinity, Gravity, Blind, Blitz, Reverse, BigBoard, Survival)
- Multiplayer online (Lobby publico, Sala privada, Matchmaking ranqueado)
- AI com 5 dificuldades e personalidades
- Battle Pass com 10 niveis
- Desafio Diario + Missoes Semanais
- Roda da Fortuna diaria
- Torneio (3 rodadas)
- Sistema de baus pos-vitoria
- Loja completa (temas, simbolos, efeitos, emotes, boosts, skins de tabuleiro)
- Perfil customizavel (avatares, bordas, titulos)
- Sistema de conquistas
- Ranked com 5 ligas + matchmaking por ELO
- Replay de partida (premium)
- Convide amigos (referral)
- Splash animada + transicoes diferenciadas
- Passe VIP mensal
- Admin config via Firebase (temas sazonais, eventos semanais)
- Leaderboard global
- Lista de amigos
- Spectator mode
